# _legacy/

Esta carpeta contiene el **intento anterior del TFI** que el alumno desarrolló pero nunca llegó a entregar. Se conserva por valor histórico y para consulta, pero **NO forma parte de la entrega final**.

## Contenido

- `_legacy/CarGross_TP/` — intento previo completo (código, manual, informe, tests, datasets).

## Por qué se conserva

- Contiene la primera implementación de ART1 que sirvió como referencia conceptual para la versión final.
- Contiene los archivos `consignas_TP.md` y `lau_contenido.md` (consigna oficial y paper Lau 1992) que dieron origen al TP actual.

## Advertencia

No incluir el contenido de `_legacy/` en la entrega final. La entrega es el contenido de la raíz del proyecto: `src/`, `docs/`, `data/`, `README.md`, `requirements.txt`.
